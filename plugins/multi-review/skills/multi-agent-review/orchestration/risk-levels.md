# 风险等级

- 低风险：2 个 reviewer。文档、注释、小配置、局部低风险修改。
- 中风险：4 个 reviewer。普通业务逻辑、多文件重构、测试或接口调整。
- 高风险：最多 6 个 reviewer。权限、支付、迁移、存档、CI/CD、外部集成、发布或关键性能路径。

先按材料内容判定材料固有风险。容纳最终数量所需最低风险为：2 人对应 low，3–4 人对应 medium，5–6 人对应 high。有效风险取材料固有风险与容纳最终数量所需最低风险的较高者。

正常 Route Decision 的数量范围为：低风险恰好 2 个；中风险 2–4 个；高风险 2–6 个。用户可以增加 reviewer；减少到两个以下必须再次确认。平台并发上限只改变批次，不改变 Router 已选角色集合。

requested reviewer 使最终数量高于自动集合时，reason 记录“手动扩展”及追加角色；excluded reviewer 使最终数量低于有效风险的自动默认数量时，reason 记录“覆盖缩减”及排除项。两者可以同时记录。low + 1 requested 的有效风险为 medium，medium=3 合法，只记录“手动扩展”；没有排除时不记录“覆盖缩减”。

用户确认少于两个 reviewer 时属于降级覆盖，最终状态必须为 incomplete，不得伪装成正常 Route Decision。
